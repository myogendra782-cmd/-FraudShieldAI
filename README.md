# FraudShield AI 🛡️

FraudShield AI is a web-based scam detection project that helps users identify suspicious SMS messages and website URLs.

## Features
- SMS scam detection
- Website URL risk analysis
- Risk scores and warning messages
- Scan history using SQLite
- Dashboard statistics
- Risk analysis chart
- Mobile-responsive design

## Technologies
- Python
- Flask
- HTML
- CSS
- JavaScript
- SQLite

## Project Structure
- frontend: HTML, CSS and JavaScript
- backend: Python Flask application and fraud detection logic

## Installation
1. Clone or download this repository.
2. Open Terminal in the backend folder.
3. Install dependencies using: pip3 install -r requirements.txt
4. Start the backend using: python3 app.py
5. Open frontend/index.html using VS Code Live Server.

## Disclaimer
Risk scores are indicators, not proof that a message or website is fraudulent or safe. This project does not guarantee real-time website reputation verification.
